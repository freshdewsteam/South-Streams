# South Streams — generated cache

This branch is written automatically by the **Update Cache** workflow and holds
only the latest generated data. Every run replaces it with a single fresh commit,
so it never accumulates history. Don't edit it by hand — changes are overwritten.

- `data/cache.json` — what the addon serves
- `data/unmatched.json` — titles that couldn't be added (fix them via `overrides.json` on main)
- `data/movies-cache.json`, `data/series-cache.json` — lookup caches
